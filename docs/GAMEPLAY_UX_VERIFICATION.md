# 布局、手记回查与行动反馈验收

日期：2026-10-25。

## 最终行为

- 大厅收紧首屏留白，1280×720 桌面和 390×844 手机视口可直接看到入席按钮。选择身份的说明位于按钮之后，不会挤走主要操作。
- 桌面保留九人环桌，改用紧凑人物卡；手机使用三列紧凑座位。手机在完整操作区不可见时显示底部行动栏，选中玩家后直接显示目标号码和确认操作；完整操作区进入视口后，快捷栏隐藏。
- 发言正文使用 16px／18px 两档字号，手记正文使用 15px／17px；字号偏好刷新后保留。辅助标签、票数和操作提示分别设置字号。
- 手记可以组合筛选天数与玩家。发言按作者筛选；投票按投票人或被投对象筛选相关轮次，汇总仍显示该轮完整票数，逐票记录可以展开。
- 怀疑、信任和声称身份是玩家自己的标记，明确标注未经证实。标记按对局保存在当前浏览器，不修改真实身份、模型上下文或服务端存档。
- 手记只在接近底部时跟随新记录；阅读旧记录时保留位置，并提供新消息入口。流式字幕更新不驱动手记滚动。
- 投票、查验、袭击、开枪、解药、毒药使用具体目标文案。切换毒药后清空旧目标；无有效目标时禁止确认。已出局、自选限制、狼队友限制、PK 候选限制和药品限制有对应说明。
- 手机手记具有模态语义、背景滚动锁定、键盘焦点循环、Esc 关闭和焦点恢复；切换到桌面尺寸时退出抽屉状态。

## 实际浏览器检查

基于生产构建，在本机独立端口和合成测试存档中操作。读取和提交动作使用真实 `/api/game` 与 `/api/game/actions`；流式消息使用本地受控 SSE 事件，AI 推进由测试夹具控制，不调用外部模型。

| 768×1024 | 无 | 无 |
| 1024×768 | 无 | 无 |
| 1280×720 | 无 | 无 |
| 1920×1080 | 无 | 无 |

完成的操作链：

1. 手机点击 5 号人物卡，确认按钮更新为“投给 5 号”；提交后显示目标姓名和成功反馈。
2. 按第 1 天与 5 号组合回查，设置“怀疑”和“声称预言家”，刷新后标记仍在；其他人的真实身份保持未知。
3. 查看放逐投票、PK 复投、平票和弃票汇总，展开逐票记录，确认汇总未因玩家筛选而缩减。
4. 在旧记录位置 `scrollTop=4498.5` 注入流式字幕与新记录，位置保持不变；出现“1 条新记录 · 回到最新”，点击后到达底部并清除未读提示。
5. 女巫切换解药与毒药，确认目标清空和禁用状态；对 5 号用毒成功。检查第三夜自救限制和毒药耗尽说明。
6. 预言家查验 3 号、狼人提议袭击 2 号、猎人对 5 号开枪、PK 弃票和文字发言均成功提交，并核对返回事件或保存的行动结果。
7. 检查手机底部操作入口、手记焦点循环、Esc 关闭、焦点恢复、背景滚动恢复，以及抽屉随桌面断点关闭。

本轮未重复执行真实 AI 模型、本地 TTS 音频和麦克风端到端验收。本地配音的已有实测结果与语音识别范围见 [配音部署说明](LOCAL_TTS.md) 和 [原验收记录](VERIFICATION.md)。
